# design_thinking_training
Open index.html, or host this folder on GitHub Pages. There is no build step, backend, API key or runtime CDN dependency.

Five lessons contain twelve worksheets. The full Wärtsilä symbol-and-name logo is copied from the existing presentation assets. The site uses the original navy, orange and gray palette and locally bundled Noto Sans.

- **Download my answers** creates a PDF directly in the browser with the answers and checkmarks from all lessons.
- **More options → Download this lesson as PDF** exports the selected lesson.
- **Print this lesson** opens the browser print dialog.
- **Save an editable copy** downloads a standalone HTML notebook, including your answers, styles, font, logo and browser PDF generator.
- The blank workbook is also available as a PDF.

Answers save in browser local storage. Keep an editable download as a portable backup. No answers are sent to a server. Start at lesson 1 and complete lessons 1–5 in order. Finishing a lesson unlocks the next. You can revisit earlier lessons. The sequence progress saves in the browser.

PDF downloads use locally bundled jsPDF 4.0.0 (MIT; license preserved in the library header), an embedded Noto Sans font, and native PDF text and tables. All paths are relative and work under a GitHub Pages project URL.

The redesigned learning studio includes a sequential five-step path, exercise shortcuts and a focused writing area. Both the working agreement and final instruction cover opening PowerPoint or prompting a slide-generation tool after testing the storyboard.

## Repository scope

This repository contains only the Design Thinking website and its local assets. The logo, fonts, PDF generator and blank workbook are included. Upload the repository contents directly to GitHub Pages; no build command or backend is required.
